# Label-blind pilot fixture correction

Date: 2026-08-13 (Asia/Calcutta)

The first successful diagnostic extraction showed that the original 1,900-character carbon-chain fixture compressed to 275 MAMMAL tokens. Its rationale said it was near the configured 2,100-token limit, so the fixture did not satisfy the frozen technical composition contract.

Before any repeatability acceptance run and without inspecting any DILI outcome or predictive-performance result, `PILOT-20` was replaced by a valid isotope-explicit carbon chain. Direct measurement with the pinned tokenizer gives approximately 2,030 tokens, below but near the locked rejection threshold. The other 19 structures, all representation settings, and the acceptance criteria are unchanged.

The earlier vector file is diagnostic and withdrawn. Both accepted repeatability runs will use only the corrected 20-row file. This record also requires per-molecule token counts, truncation status, special-token layout, and tokenizer warnings in the extraction manifest.
